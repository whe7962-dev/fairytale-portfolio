# 何选 · AI 产品学习与实践

Vite + 原生 JavaScript 的单页项目。以横屏宽银幕布局为主，同时适配手机。已按何选提供的资料更新姓名、求职方向、已学习内容、学历、公众号现名与联系方式。当前以学习内容为主，尚无已完成的可展示项目。电影开场、主页平滑滚动和章节入场已启用。

## 本地预览

需要 Node.js 22.12+。首次从 GitHub 获取项目，在终端执行：

```bash
git clone https://github.com/whe7962-dev/fairytale-portfolio.git
cd fairytale-portfolio
npm ci
npm run dev
```

已有本地项目时，在项目目录执行 `npm ci` 和 `npm run dev` 即可。源码仓库已公开，可以直接克隆。

打开终端显示的地址，通常是 **http://127.0.0.1:5173/**。请通过 Vite 访问，不要直接双击 `index.html`。

构建与检查生产版本：

```bash
npm run build
npm run preview
```

预览命令通常使用 **http://127.0.0.1:4173/**。端口占用时以终端实际输出为准。

## 在线访问与部署

网站地址：[何选 · AI 产品学习与实践](https://whe7962-dev.github.io/fairytale-portfolio/)。

GitHub Pages 通过 `.github/workflows/deploy-pages.yml` 自动部署。每次向 `main` 推送更新后，工作流使用 Node.js 24、`npm ci` 和 `npm run build:pages` 构建，只上传 `dist/` 中的网站文件。可在仓库 Actions 页面查看构建和部署结果，也可手动运行工作流。

`build:pages` 将 Vite 的 `base` 设置为 `/fairytale-portfolio/`，使脚本、样式、图片和视频都从正确的子目录加载。本地开发仍使用根路径；要预览 Pages 构建，可运行 `npm run build:pages`、`npm run preview -- --base=/fairytale-portfolio/`，再访问 **http://127.0.0.1:4173/fairytale-portfolio/**。

网站部署不包含 `source-assets/` 中的原始视频；原件仍保留在公开源码仓库中。

## 连续开场与预览

正常首次访问自动播放一次；同一标签页内刷新不重复打断，带章节锚点的链接直接进入对应内容。点击页脚「重播开场」可再次播放；每次重播结束或跳过均落在首屏。

开发时可直接使用：

- **http://127.0.0.1:5173/?intro=play**：每次刷新都播放。
- **http://127.0.0.1:5173/?intro=skip**：直接进入主页。
- **http://127.0.0.1:5173/?intro=preview**：保留手动切换的静态分镜，方便检查素材与文字。

顺序：**黑场 → 白魔杖 → 姓名与一行简介 → 草地与白神光 → 白蝴蝶 → 主页**。正常约 14 秒，取决于视频实际时长和加载速度。魔杖播放一遍；草地镜头延续到蝴蝶阶段，播放结束后保留尾帧，再淡入主页。过渡使用 `sine.inOut / sine.out`，没有弹跳或闪烁。

Skip 与 Esc 全程可用。播放时锁定背景滚动和焦点，退出时停止所有视频、取消计时与动画、恢复页面及键盘访问。视频加载等待上限 2.5 秒，播放启动等待上限 1.4 秒；加载失败或浏览器拒绝播放时使用静帧继续，不会停在黑场。单次开场另设 25 秒兜底。后台标签页回到前台时可能已经进入主页。

系统开启「减少动态效果」时直接进入主页，页脚改为「查看开场分镜」，不会强制播放视频。静态分镜支持方向键、Home / End、Tab、Esc，退出后返回原滚动位置与触发按钮。

| `hero-grassland.jpg` | 首屏 / 开场的草地底图 | 从第二段视频的偏冷网页版本提取 0.8 秒静帧 |
| `hero-godrays.mp4` | 草地与白色光束的完整场景 | 已接入「视频+2.mp4」，1280×720，约 4 秒，降暖调色、压缩并移除音轨 |
| `butterflies-loop.mp4` | 白色蝴蝶叠层 | 纯色静帧占位，不参与播放；目前使用三只月光白 SVG 飞入 |
| `pumpkin-spawn.mp4` | 作品章南瓜 / 南瓜车 | 有效的 1 秒无声静帧 MP4 |

额外的 `loader-wand-poster.jpg` 提取自第一段网页视频的 2.6 秒，用于开场分镜的静态预览。两段网页视频均使用 H.264 / yuv420p、24fps 与 faststart，合计约 3.9 MB；原始音轨已从网页版本移除，原件不改动。

视频均保持 `muted`、`playsinline`，没有 HTML `autoplay` 属性。仅在启动连续开场时为两段真实视频赋予 `src` 并加载，由控制器调用 `play()`；结束或跳过时暂停并移除来源。静态预览、减少动态效果或跳过自动开场时不会加载这两段开场视频。主页中的视频槽仍隐藏且 `preload="none"`。独立蝴蝶与南瓜车视频仍为纯色静帧占位，未启用播放。

后续同名替换魔杖 / 草地视频时，请同步更新对应的 JPG 静帧。独立蝴蝶视频准备好后，还需在 `src/intro.js` 与开场结构中接入，当前不会把纯色占位当成可播放内容。

原件完整复制在 `source-assets/`，该目录不进入生产构建；下载目录中的原文件也未修改。`docs/media-manifest.json` 记录原文件名、校验值、网页路径、静帧时间与调色参数。原视频中的「AI 生成」标记保留。

第二段原片偏金暖，网页副本按既定要求调整为偏冷的白色光线、森林绿草地。它包含完整背景与白色飞舞元素，**不是透明神光叠层**；开场按完整镜头单次播放，不做硬切循环。蝴蝶阶段沿用这一镜头，只补充三只小型前景 SVG 蝴蝶，不重复叠放视频。

`scripts/create-placeholders.py` 仅用于生成初始占位，需要 Pillow、numpy、imageio-ffmpeg。检测到已接入的素材清单时会直接退出，避免覆盖用户视频和新静帧。

## 动效边界

开场采用 GSAP 淡入淡出、轻微位移与蝴蝶振翅，并接入两段真实静音视频。主页采用 Lenis + GSAP ScrollTrigger；`src/motion.js` 的 `motionConfig` 集中管理节奏：

- `smoothScroll: true`：启用鼠标滚轮平滑滚动，滚动和锚点定位使用 `1.25s` 正弦缓动。手机手指滚动保留原生行为，`syncTouch` 为 `false`。
- 标题、正文和学习主题在接近视口底部（88%）时首次淡入，时长 `0.9s`；桌面上移 `18px`，窄屏上移 `12px`，使用 `sine.inOut`。已读内容不会随回滚重复出现。
- 点击目录会保留 URL 锚点、更新键盘焦点，并按 CSS 的 `scroll-padding-top` 避让固定页头。跳至主要内容入口立即生效；展开清单、窗口尺寸或字体布局变化会重新校准滚动位置。
- 开场或静态分镜打开时，暂停并释放主页滚动与入场动画；退出后重新建立，避免重播结束时被旧滚动惯性拉回页脚。Hero 的过渡仍由开场独立管理。
- 系统开启「减少动态效果」后立即移除 Lenis、滚动入场及临时隐藏样式，恢复原生浏览；设置关闭后自动恢复。键盘聚焦的内容会立即显示，Page Up / Down 等原生按键可打断惯性。

颜色和布局沿用现有设计；本轮没有添加视差、滚动锁屏、光标特效或新的素材要求。
